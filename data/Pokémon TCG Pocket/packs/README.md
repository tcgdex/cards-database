# Pocket event packs

Event packs reference original card printings by API ID. The game master identifies Vee Vee! Eevee Pack as `EVP002_0010_00_000` with no expansion ID. All 51 printings match the `cards.available` entries in the pinned [C1 game master snapshot](../../../meta/pocket-source-reviews/C1/master.json). When a game ID maps to multiple printings, use the set and collector number on the event pack card list.

- [Serebii pack list and artwork](https://www.serebii.net/tcgpocket/promo/veevee%21eeveepack.shtml) confirms the 51 printings and slot membership. Its rounded percentages are excluded from the data.
- [Pokémon Zone pack list](https://www.pokemon-zone.com/packs/97/) provides a second public pack reference.
- [Serebii's event record](https://www.serebii.net/tcgpocket/events/veeveeeeveemissions.shtml) dates public distribution to November 20, 2026. The game master's October 29 timestamp describes the data entry.
- The C1 `EVP_3` game dictionaries confirm names for `en`, `es`, `fr`, `pt-br`, `zh-tw`, `ja` and `ko`. Latin-script singular forms are used for the individual pack. German and Italian use localized display names.
- The pack artwork is the published Serebii PNG trimmed to its alpha bounds and converted losslessly to WebP. The public object has SHA-256 `f3483c52b729901e353467afabc7c5eb5543013e4da75d5dde91880088672a54`. Card art and rules come from each original printing.
